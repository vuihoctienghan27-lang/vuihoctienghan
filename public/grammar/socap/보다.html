NGỮ PHÁP SƠ CẤP

CẤU TRÚC SO SÁNH [보다]

I. MỤC TIÊU BÀI HỌC

  • Kiến thức: Học sinh hiểu được ý nghĩa và cách dùng của trợ từ so sánh 보다 để diễn đạt sự so sánh hơn.
  • Kỹ năng: Học sinh có thể sử dụng cấu trúc N + 보다 + N + 이/가 + Adj để so sánh hai đối tượng.
  • Thái độ: Hình thành thói quen sử dụng đúng cấu trúc so sánh trong giao tiếp tiếng Hàn.

II. NỘI DUNG BÀI HỌC

1. Định nghĩa & Ý nghĩa

  • 보다 là trợ từ so sánh trong tiếng Hàn, có nghĩa là "hơn".
  • Được đặt sau danh từ được đem ra so sánh: N1보다 N2가 = "N2 hơn N1".

2. Ngữ cảnh sử dụng

Cấu trúc 보다 được dùng phổ biến trong:

  • So sánh đồ uống: 커피보다 차
  • So sánh thời gian: 어제보다 오늘
  • So sánh địa điểm: 한국보다 베트남
  • So sánh sở thích: 책보다 영화
  • So sánh người: 형보다 동생

3. Cấu trúc ngữ pháp & Quy tắc viết

N1 + 보다 + N2 + 이/가 + Tính từ
N2 hơn N1 (N2 + Adj)

Lưu ý quan trọng:

  • 보다 luôn đứng sau danh từ được so sánh.
  • Có thể kết hợp với 더 (thêm) để nhấn mạnh: 더 + Tính từ.
  • Cấu trúc đầy đủ: 보다 thường đi với 이/가 ở danh từ thứ hai.

III. VÍ DỤ MINH HỌA

Dưới đây là 5 ví dụ đa dạng tương ứng với các ngữ cảnh thực tế khác nhau:

🔹 Ví dụ 1: So sánh đồ uống

  • Câu tiếng Hàn: 커피보다 차가 좋아요.
  • Cách phát âm: [keo-pi-bo-da cha-ga jo-a-yo]
  • Dịch nghĩa: Tôi thích trà hơn cà phê.

🔹 Ví dụ 2: So sánh thời gian

  • Câu tiếng Hàn: 어제보다 오늘이 더 더워요.
  • Cách phát âm: [eo-je-bo-da o-neu-ri deo deo-wo-yo]
  • Dịch nghĩa: Hôm nay nóng hơn hôm qua.

🔹 Ví dụ 3: So sánh địa điểm

  • Câu tiếng Hàn: 한국보다 베트남이 더 커요?
  • Cách phát âm: [han-guk-bo-da be-teu-na-mi deo keo-yo]
  • Dịch nghĩa: Việt Nam rộng hơn Hàn Quốc phải không?

🔹 Ví dụ 4: So sánh sở thích

  • Câu tiếng Hàn: 책보다 영화가 재미있어요.
  • Cách phát âm: [chaek-bo-da yeong-hwa-ga jae-mi-i-sseo-yo]
  • Dịch nghĩa: Phim thú vị hơn sách.

🔹 Ví dụ 5: So sánh người

  • Câu tiếng Hàn: 형보다 동생이 더 커요.
  • Cách phát âm: [hyeong-bo-da dong-saeng-i ki-ga deo keo-yo]
  • Dịch nghĩa: Em cao hơn anh.

IV. BÀI TẬP VẬN DỤNG
